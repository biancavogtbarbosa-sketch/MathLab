Função de 1º Grau

f(x) = ax + b

Representa uma reta no plano cartesiano. O gráfico é uma linha que cruza os eixos dependendo dos coeficientes.

  • a → Inclinação da reta (taxa de variação)
  • b → Onde a reta corta o eixo Y (intercepto)
🌊

Função de 2º Grau

f(x) = ax² + bx + c

Desenha uma parábola no plano cartesiano. Sua forma depende dos três coeficientes.

  • a → Concavidade (para cima se a>0, para baixo se a<0)
  • b → Inclinação na origem e posição do vértice
  • c → Onde a parábola corta o eixo Y
🎯

Discriminante (Δ)

Δ = b² − 4ac

O valor de Δ determina quantas raízes reais a função do 2º grau possui:

  • Δ > 0 → Duas raízes reais distintas
  • Δ = 0 → Uma raiz real (dupla)
  • Δ < 0 → Nenhuma raiz real
⭐

Vértice da Parábola

V = (xᵥ , yᵥ)

O ponto mais alto ou mais baixo da parábola, onde ocorre o valor máximo ou mínimo da função.

  • xᵥ = −b / 2a
  • yᵥ = −Δ / 4a

Lançamento de Projéteis

A altura de um objeto lançado verticalmente segue uma função do 2º grau:

h(t) = −5t² + v₀t + h₀

Problema: Um foguete de brinquedo é lançado do solo com velocidade inicial de 20 m/s. Qual a altura máxima atingida e em que momento ele volta ao solo?

Solução Passo a Passo:

  1. Função: h(t) = −5t² + 20t (com h₀ = 0)
  2. Coeficientes: a = −5, b = 20, c = 0
  3. Vértice (altura máxima): tᵥ = −b/2a = −20/(2·−5) = 2 segundos
  4. h(2) = −5(4) + 20(2) = −20 + 40 = 20 metros
  5. Raízes (volta ao solo): −5t² + 20t = 0 → t(−5t + 20) = 0 → t = 0 ou t = 4 segundos

Lucro Máximo de uma Empresa

O lucro pode ser modelado por uma função quadrática quando há custos variáveis e receita proporcional à quantidade vendida:

L(q) = −2q² + 100q − 800

Problema: Uma fábrica tem lucro L(q) = −2q² + 100q − 800, onde q é a quantidade produzida. Quantas unidades devem ser produzidas para maximizar o lucro?

Solução Passo a Passo:

  1. Coeficientes: a = −2, b = 100, c = −800
  2. Como a < 0, a parábola tem concavidade para baixo → há lucro máximo
  3. Quantidade ótima: qᵥ = −b/2a = −100/(2·−2) = 25 unidades
  4. Lucro máximo: L(25) = −2(625) + 100(25) − 800 = −1250 + 2500 − 800 = R$ 450
  5. Ponto de nivelamento (L=0): Δ = 10000 − 6400 = 3600 → √Δ = 60
  6. q = (−100 ± 60)/(−4) → q₁ = 10 e q₂ = 40 (empresa lucra entre 10 e 40 unidades)

Design de Arcos e Pontes

A forma de muitos arcos arquitetônicos segue uma parábola, distribuindo forças de maneira eficiente:

y = −0,1x² + 4

Problema: Um arco de ponte tem formato parabólico dado por y = −0,1x² + 4 (em metros). Qual a altura máxima do arco e a distância entre seus apoios?

Solução Passo a Passo:

  1. Coeficientes: a = −0,1, b = 0, c = 4
  2. Altura máxima (vértice): yᵥ = −Δ/4a = −(0 − 4·(−0,1)·4)/(4·−0,1) = 1,6/(−0,4) → 4 metros
  3. Apoios no solo (y = 0): −0,1x² + 4 = 0 → x² = 40 → x = ±√40 ≈ ±6,32
  4. Distância entre apoios: 2 · 6,32 ≈ 12,64 metros
