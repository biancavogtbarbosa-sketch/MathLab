# 🎓 MathLab — Funções Polinomiais Interativas

Um site educativo moderno e interativo sobre **Funções Polinomiais de 1º e 2º Graus**, desenvolvido com HTML5, CSS3 e JavaScript Vanilla.

![Status](https://img.shields.io/badge/status-online-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

## 🚀 Sobre o Projeto

O **MathLab** foi criado para tornar o aprendizado de funções polinomiais mais visual, dinâmico e divertido. Através de simuladores interativos, os estudantes podem manipular coeficientes em tempo real e observar como a função se comporta no plano cartesiano.

### ✨ Funcionalidades

- 🎨 **Design moderno** com tema dark e efeitos neon (glassmorphism)
- 📈 **Laboratório interativo** com sliders para manipular `a`, `b` e `c` em tempo real
- 🧮 **Cálculos automáticos** de raízes, vértice, discriminante e concavidade
- 🌍 **Aplicações reais** em Física, Economia e Engenharia
- 🧠 **Desafio dinâmico** para testar conhecimentos
- 📱 **Totalmente responsivo** (Desktop, Tablet e Mobile)
- ⚡ **Sem dependências** — apenas HTML, CSS e JS puro

## 🛠️ Tecnologias

- **HTML5** semântico e acessível
- **CSS3** com variáveis, grid, flexbox e animações
- **JavaScript Vanilla** (sem frameworks)
- **Canvas API** para renderização dos gráficos
- **Google Fonts** (Poppins e JetBrains Mono)
